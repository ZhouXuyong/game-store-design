Prerequisites
MAMP or similar local server environment

Web browser with PHP support

Apache server

MySQL database (if database functionality is implemented)

Installation & Setup
Clone or download the project files

Place in web server directory:
/Applications/MAMP/htdocs/game_store/
Start MAMP and ensure Apache server is running

Access the website:
http://localhost:8888/game_store/
